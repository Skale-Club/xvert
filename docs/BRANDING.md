# Xvert branding

Xvert is the media converter in the Skale Club family. Its icon is two glossy cobalt arrows turning
around an icy white play button, on transparency, in the same beveled style as the family.
The master is icon-source.png (1254 x 1254 RGBA). It has no navy tile or decorative outer border.
Run ./make-icon.ps1 to regenerate Tauri icons and src/logo.png.
The build script tracks the ICO/PNG files and npm run build checks the embedded PE icon.
The Skale Club organization mark is a separate asset.
